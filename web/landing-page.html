// 001  ·  About

The Arena
Awaits

conveyor-engine-arena is a fully open-source, engine-first FPS arena game set in a decaying Soviet-bloc megacity. Matches play out across rooftop plazas threaded with live conveyor belts — dynamic cover, forced movement, no camping.

Built in the open from day one. MIT licensed. Fork it, mod it, break it. The engine and the game are the same codebase.

// 002  ·  Features

Engine
Capabilities

⬡

Conveyor Mechanics

Live conveyor belts reshape the battlefield each round. Position is never static — momentum is the weapon.

◈

Brutalist Maps

Rooftop arenas modelled on Soviet-bloc megablock architecture. Dense, vertical, with destructible surface detail.

◇

Custom Renderer

Deferred teal-toned lighting pipeline with emissive accent layers, baked AO and per-material rust-decay maps.

▶

Moddable Engine

Game and engine share one codebase. Fork, extend, replace any system. Full map SDK included.

⬡

Networked Arenas

UDP lockstep netcode with server-authoritative physics. Low-bandwidth design, works on bad connections.

◈

Zero Vendor Lock-in

MIT license, no runtime fees, no telemetry. Self-host your own server. Own your match data.

// 004  ·  Install

Get
Running

Requires Node 22.18 or newer. Clone the repo, install, then build and start the host and open the URL it prints (127.0.0.1, set PORT to change it). Full docs in README.md.

git clone https://github.com/autonomous1/conveyor-engine-arena.git
cd conveyor-engine-arena && npm install
npm run dev
